## Relevance
- Bears on hypotheses: H3 refutation (direct anecdotal + platform-level evidence that interviewers almost never open repos — even for a top-1K-followed developer like Dan Luu), H1 stress-test (most portfolio projects are curriculum clones adding little signal), and the general premise "projects impress CV reviewers".
- 3-line summary: A data scientist analyzes GitHub Archive and finds the vast majority of GitHub users are essentially invisible (83% no commits in the past year), most existing projects are unimpressive boilerplate, and stars/followers measure popularity, not talent (a fake TV-show profile outranks 99.998% of developers). Two independent practitioner accounts report that essentially no interviewer looked at their public code — including one of the most-followed GitHub users. This is the strongest quantitative disconfirming evidence in this channel, though it predates the AI-era portfolio inflation.
